#  Sentiment Analysis Application

##  Overview

This project develops a Natural Language Processing application capable of analyzing the sentiment and emotions expressed in a text.
The application predicts whether a text expresses a positive, negative, or neutral sentiment and provides additional emotional analysis through a web interface.

##  Objectives

* Build an NLP preprocessing pipeline
* Apply machine learning techniques to text data
* Analyze sentiment
* Deploy a prediction interface using Flask


##  Features

* Sentiment classification
  

##  Technologies

* Python
* Flask
* NumPy
